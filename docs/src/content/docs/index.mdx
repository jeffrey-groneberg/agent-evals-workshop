## What you'll learn

<CardGrid>
  <Card title="The basics, explained" icon="open-book">
    What an eval is, why AI agents need them, and the parts every eval has: task, agent, environment, trials, transcript, graders and score.
  </Card>
  <Card title="Check your checks, for free" icon="approve-check">
    Prove your checks catch a wrong answer before you spend a single token, with Vally's mock executor.
  </Card>
  <Card title="Measure a real bug" icon="magnifier">
    Run GitHub Copilot as the agent under test, three trials at a time, and read the transcript to see why it fails.
  </Card>
  <Card title="Prove the fix" icon="random">
    Fix the agent's skill and prove the fix with a controlled experiment: same eval, same model, one change.
  </Card>
  <Card title="Add an LLM judge" icon="star">
    Write a rubric and calibrate an LLM judge for the qualities a string check can't see. It runs on Copilot; your own model endpoint is optional.
  </Card>
  <Card title="GitHub Copilot Evals" icon="github">
    Let Copilot review, create, run and compare evals, and judge its drafts with what you learned.
  </Card>
</CardGrid>

## How the workshop flows

<Flow
  label="The workshop path"
  steps={[
    { label: 'Basics', detail: 'What an eval is and the parts it has', tone: 'input' },
    { label: 'Vally by hand', detail: 'Write, run and read evals in YAML and the terminal', tone: 'agent' },
    { label: 'LLM judge', detail: 'A rubric, and a second model that applies it', tone: 'grader' },
    { label: 'GitHub Copilot Evals', detail: 'Copilot helps you create, review, run and compare', tone: 'result' },
  ]}
/>

You'll work on one small, real example the whole time: a **release-notes skill** that drafts release notes from a backlog. It has a bug: it announces work that isn't finished yet. You'll catch it, measure it, fix it and prove the fix. The guided part takes about two hours; the self-paced labs (CI, comparing models, your own agent) you finish at home.
