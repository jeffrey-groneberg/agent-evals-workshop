## Sources

The concepts in this workshop draw on these sources:

- **Vally documentation**: [microsoft.github.io/vally](https://microsoft.github.io/vally/), in particular the [eval file reference](https://microsoft.github.io/vally/reference/eval-spec/), [experiment files](https://microsoft.github.io/vally/reference/experiment-file/), [graders](https://microsoft.github.io/vally/reference/graders/) and [runtime setup](https://microsoft.github.io/vally/get-started/runtime-setup/).
- **GitHub Copilot Evals documentation**: [github.github.io/evals](https://github.github.io/evals/), including the [release-note control example](https://github.github.io/evals/examples/release-note-control.eval.yaml).
- **`github/evals-action`**: [README](https://github.com/github/evals-action).
- **GitHub Docs**: [Authenticating GitHub Copilot CLI](https://docs.github.com/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli).
- **Anthropic**: [Demystifying evals for AI agents](https://www.anthropic.com/research/demystifying-evals-for-ai-agents): tasks, trials, graders, transcripts, capability and regression evals, pass@k and pass^k.
- **Chen et al., 2021**: [Evaluating Large Language Models Trained on Code](https://arxiv.org/abs/2107.03374): the unbiased pass@k estimator.
- **Zheng et al., 2023**: [Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena](https://arxiv.org/abs/2306.05685): LLM judges' agreement with humans, and their biases.
