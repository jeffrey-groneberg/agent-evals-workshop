## 你将学到什么

<CardGrid>
  <Card title="讲清基础知识" icon="open-book">
    什么是评估（eval）、AI 智能体为什么需要评估，以及每个评估都具备的组成部分：任务、智能体、环境、试验、运行记录（transcript）、评分器和分数。
  </Card>
  <Card title="免费检查你的检查项" icon="approve-check">
    借助 Vally 的模拟执行器（mock），在花费任何一个 token 之前，先证明你的检查项能发现错误答案。
  </Card>
  <Card title="量化一个真实的 bug" icon="magnifier">
    把 GitHub Copilot 作为被测智能体来运行，每次进行 3 次试验，并阅读运行记录，弄清它为什么失败。
  </Card>
  <Card title="证明修复有效" icon="random">
    修复智能体的技能（skill），再用受控实验证明修复有效：同一个评估、同一个模型，只改动一处。
  </Card>
  <Card title="添加 LLM 评审" icon="star">
    编写评分标准（rubric）并校准 LLM 评审，让它评判字符串检查项看不出来的质量。它在 Copilot 上运行；你也可以选择使用自己的模型终结点。
  </Card>
  <Card title="GitHub Copilot Evals" icon="github">
    让 Copilot 审查、创建、运行和比较评估，并用你学到的知识评判它起草的内容。
  </Card>
</CardGrid>

## 工作坊流程

<Flow
  label="工作坊路线"
  steps={[

整个工作坊都围绕同一个真实的小例子展开：一个根据待办事项列表起草发布说明的**发布说明技能**。它有一个 bug：会把尚未完成的工作也公布出来。你将发现这个 bug，衡量它，修复它，并证明修复有效。引导部分大约需要 2 小时；自定进度练习（CI、比较模型、你自己的智能体）可以回家后再完成。
