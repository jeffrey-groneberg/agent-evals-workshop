本页面写给带领工作坊的讲师。参与者可以跳过本页。

## 提前两周

- **亲自在起始存储库的一个全新副本中把完整流程走一遍**：使用 Codespace，并以参与者的权限完成练习 0 到 6（包括 GitHub Copilot Evals 插件）。预览版工具变化很快；这些练习是在 2026 年 11 月用 Vally 0.21.0 测试的。
- **对照本站点检查起始存储库**：使用本站点存储库中的 `tools/verify-starter.sh`（参见该存储库的 README）。它不需要模型，也不需要任何凭据。
- **检查参与者的 Copilot 计划**。Business 和 Enterprise 计划下的组织必须允许使用 Copilot CLI。如果许多参与者来自同一个组织，请尽早联系该组织的管理员。练习中固定使用两个 Copilot 模型：智能体用 `claude-sonnet-5.5`，评审用 `gpt-5.6-luna`。无法使用其中某个模型的参与者，可以用 `./scripts/use-model.sh <model-id>`（智能体）或 `--param JUDGE_MODEL=<model-id>`（评审）切换模型。
- **决定 LLM 评审在哪里运行**。默认情况下，每位参与者的评审和智能体一样，都在他们自己的 Copilot 计划上运行，因此不需要分发任何密钥。如果你希望集中支付评审费用，请向参与者提供终结点、短期有效的密钥，以及某个 GPT-5 系列模型的部署名称（例如 Azure OpenAI 或 Microsoft Foundry 中的部署），并让他们参阅[使用你自己的模型终结点](../../start/model-access/#你自己的模型终结点可选)。请先用 `./scripts/check-setup.sh --ping` 测试，并按练习 5 中每位参与者约 11 次评审调用来做规划。切勿共享长期有效的密钥或管理员密钥。
- **发送“工作坊开始前”清单**（见[概述](../../start/overview/#工作坊开始之前)）：Copilot 计划、起始存储库的副本、Codespace（或已用 `gh auth login` 登录的本地环境）、检查脚本。

## 工作坊当天

- 打开本站点和你自己的 Codespace。
- 如果你提供集中的评审终结点，请在练习 5 之前分发终结点、密钥和部署名称，并让参与者用 `./scripts/check-setup.sh --ping` 测试。
- 别忘了 `scripts/catch-up.sh`：任何进度落后的人都可以直接跳到任一练习的结束状态，然后继续。如果只想对照而不想跳过，练习 2 和练习 4 到 7 的**参考答案**部分展示了完成版文件。

## 参与者常问的问题

**为什么使用模拟执行器（mock）**？它会把提示词作为答案返回，因此你可以把已知的答案交给检查项：免费、即时、结果确定，而且任何错误的判定结果都只能归咎于检查项本身。这是有文档记载的最佳实践。参见[评分器：为什么使用模拟执行器](../../concepts/graders/#为什么使用模拟执行器)。

**我们需要特定的模型吗？结果是确定性的吗**？不需要，也不是。练习中固定了模型，是为了让结果可以相互比较；使用三次试验，是因为智能体的表现会变化。如果没有 `claude-sonnet-5.5`，运行一次 `./scripts/use-model.sh <model-id>`；如果没有 `gpt-5.6-luna`，在带评审的运行中加上 `--param JUDGE_MODEL=<model-id>`。代码检查项和模拟执行器是确定性的。参见[模型访问](../../start/model-access/#固定模型可比较但非确定性)。

**为什么邻座的运行通过了，我的却失败了**？这是试验之间的差异。比较一下哪些检查项失败了，并阅读答案。

**Vally 和 GitHub Copilot Evals 有什么区别**？Vally 是引擎；GitHub Copilot Evals 是构建在它之上的助手，它的运行都在 Vally 中完成。参见[这两个工具](../../concepts/tools/)。

**为什么要用另一个模型当评审**？因为存在自我偏好偏差：模型给自己所属模型系列的输出打分会更宽松。在练习中，由 GPT 模型评审 Claude 模型。

**我需要 API 密钥吗**？不需要。智能体和评审都通过你的 Copilot 登录在 GitHub Copilot 上运行。只有使用你自己的模型终结点时才需要密钥：密钥放在环境变量中（Codespaces 机密或 `.env`），评估文件中只写变量名。

**回家后怎么继续**？你的 Codespace 和你的起始存储库副本仍然归你所有，评审也会继续在你的 Copilot 计划上运行。如果你在工作坊中使用了工作坊提供的密钥进行评审，那么在密钥过期后，从评估文件中删除 `judge_provider` 块，评审就会重新在 Copilot 上运行。

## 工作坊结束后

- 提醒参与者停止或删除他们的 Codespace，并删除他们为练习创建的个人访问令牌（如果有）。
- 如果你为集中评审终结点分发过密钥，请吊销这些密钥。
- 收集反馈，并为出过问题的地方创建议题（issue）。
