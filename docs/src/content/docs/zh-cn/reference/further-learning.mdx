## 参考资料

本工作坊中的概念参考了以下资料：

- **Vally 文档**：[microsoft.github.io/vally](https://microsoft.github.io/vally/)，尤其是其中的[评估文件参考](https://microsoft.github.io/vally/reference/eval-spec/)、[实验文件](https://microsoft.github.io/vally/reference/experiment-file/)、[评分器](https://microsoft.github.io/vally/reference/graders/)和[运行时设置](https://microsoft.github.io/vally/get-started/runtime-setup/)。
- **GitHub Copilot Evals 文档**：[github.github.io/evals](https://github.github.io/evals/)，包括其中的[发布说明对照用例示例](https://github.github.io/evals/examples/release-note-control.eval.yaml)。
- **`github/evals-action`**：[README](https://github.com/github/evals-action)。
- **GitHub 文档**：[对 GitHub Copilot CLI 进行身份验证](https://docs.github.com/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli)。
- **Anthropic**：[Demystifying evals for AI agents](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)：任务、试验、评分器、运行记录（transcript）、能力评估和回归评估，以及 pass@k 和 pass^k。
- **Chen 等，2021**：[Evaluating Large Language Models Trained on Code](https://arxiv.org/abs/2107.03374)：无偏的 pass@k 估计量。
- **Zheng 等，2023**：[Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena](https://arxiv.org/abs/2306.05685)：LLM 评审与人类判断的一致程度，以及它们的偏差。
